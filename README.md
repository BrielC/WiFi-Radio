# WiFi-Radio
This is a WiFi radio that is using a ESP32-S3 and a PCM5100 as main components. To select the different stations it is using a rotary encoder and its using a 16x2 LCD display as output device. It is currently loaded with 45 radio stations of which the most is in the Afrikaans language.
Radio station URLs can be found using the following links:
https://fmstream.org/index.php
https://www.radio-browser.info/map
https://streamurl.link/country/
